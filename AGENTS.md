# AGENTS.md — grafnot

React 19 + TS strict + Vite, данные только в localStorage. Общие правила (язык, среда, гейты, GitHub) — корневой `AGENTS.md`. Редизайн S0–S13 завершён; исходный промпт — `docs/archived/Redesign_S0-S13_prompt.md` (читать только при споре о замысле).

## Неприкосновенно (только внешний вид и место показа)
`store.ts` (схема, `migrate`, `LoadResult`), `profiles.ts`, `storage/profileBoot.ts`, конвейер сохранения (`flushSave`, `saveState`, `lastSeenRaw`, баннеры blocked/conflict/failed), `exportRaw`, логика ErrorBoundary. Новые UI-настройки — аддитивно через prefs/listPrefs с ключом профиля.

## Как работать
- «Красный первым»: тест на новое поведение падает на старом коде (имя + первая строка ошибки), затем исправление.
- Тесты используют testid и role, не тексты и классы. Контракт testid — `README.md` §UI; изменение фиксировать там.
- Регрессии данных (группы G11–G17, G30–G32) не ослаблять.
- Старый компонент и его CSS удаляются в той же правке, где появился новый; страницы остаются lazy-чанками.
- Длинные RU/KZ строки не должны ломать раскладку.
- E2E: проверки в `e2e/groups/<группа>.cjs`, читать только нужную группу. Перед правкой — `docs/e2e-notes.md`.
- Гейты одной командой, в отчёт — её таблица: на шаге `npm run gates -- --groups=<затронутые>`, в конце этапа `npm run gates -- --e2e`. Preview она поднимает и гасит сама; полные логи — `%TEMP%\grafnot-gates\<гейт>.log`, читать только упавшие.

## Нормы UI (N1–N9)
- N1 Цели: touch ≥ 44×44 (`--hit-min`), mouse: текст ≥ 32 px, иконка ≥ 36×36; зазор ≥ 8 px, деструктивное ≥ 24 px от основного и не в одном ряду; строка списка — цель открытия. Проверка: `scripts/audit-targets.cjs enforce`.
- N2 Позиция: попап у триггера; модалка только для необратимого и блокирующих ошибок; основная кнопка формы в конце потока (mobile — во всю ширину, sticky), «Отмена» слева.
- N3 Ввод: label над полем, автофокус на первом (новая заметка — сразу в тексте; заголовок перед текстом в Tab), Enter подтверждает, Esc отменяет, Tab = визуальный порядок; нет действий только по hover.
- N4 Обратимость: удаление сразу + Undo 8 с; ConfirmDialog только для очистки корзины и удаления профиля.
- N5 ≤ 7 пунктов в группе, редкое в «⋯», последний выбор запоминается.
- N6 Отклик ≤ 100 мс, у пустого состояния одно основное действие.
- N7 Клавиши: `/` поиск страницы, Ctrl+K палитра, N новый элемент, Ctrl+Enter главное действие, стрелки по спискам, Delete с Undo. Реестр — `src/shortcuts.ts`.
- N8 Контраст ≥ 4.5:1 в обеих темах (`npm run check:contrast`), видимый фокус, смысл не только цветом, aria-имя у иконочных кнопок (i18n ×3), `prefers-reduced-motion`.
- N9 Списки без селектора лимита: порции по 50, «Показано X из Y».

## Архитектура UI
Разделы: Заметки, Планировщик (Список | Неделя), Карта, Промпты; Настройки (Профили, Внешний вид, Корзина, Клавиши, Данные). Маршруты: `#/notes/:id`, `#/plan/list|week`, `#/map/:graphId`, `#/map/note/:noteId`, `#/prompts/:itemId`, `#/settings/:section`. Desktop: rail 224/64 px; mobile: tab bar [Заметки][План][+][Карта][Промпты]. Палитра — поиск и команды; создание — «+»/«Вставить». Контекст закрыт по умолчанию, три вкладки (Связи, Задачи, Промпты); закрепление оставляет редактору ≥560 px, в узком окне панель временная. Mobile: профиль/настройки и статус сохранения в шапке; «+» с видимой подписью действия по разделу, три режима в Настройках.
