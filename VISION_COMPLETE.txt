Grafnot — образ полностью завершенного проекта
Дата: 02.10.2026. Статус: vision-doc, не ТЗ. Сверено с кодом grafnot-prototype/src и README 24.09.2026.

1. ЧТО ЕСТЬ СЕЙЧАС (факт, без скидок)
- Заметки: Tiptap B/I/H/списки/undo-redo, черновик заголовка, счетчик слов, экспорт .md одной заметки, дублирование, заготовки, похожие <=3. Нет: истории версий, импорта .md, картинок/таблиц, офлайн-папки Vault.
- Задачи: экраны Активные/Выполненные/Все, диалог (название/описание/дата ISO), noteId + чип «из:», корзина trashTasks + arm-confirm. Нет: повторов, напоминаний, Kanban, приоритетов.
- Календарь: только неделя Пн-Вс, клик по дню подставляет дату, «Без даты». Нет: месяца, drag-and-drop, повестки дня.
- Карта: SVG 800x500, force 300 тиков без таймера, drag/pan/zoom 0.4-2.5, хит r=24, Pro-замок 20 заметок, сироты/битые в разрезе скопа. Нет: realtime-физики, миникарты, фулскрина, фильтра по типу связи, perf-теста на 10k.
- Промпты: словарь-сэмпл v1.0.0-sample 2026-09-15, 57 тегов, RISK_THRESHOLD=50, renderPrompt Pony/SDXL/Flux, сохранения PromptSave[] + привязка noteId односторонняя. Нет: реального частотного словаря Danbooru, совместимости тегов, живой статистики.
- Стор: localStorage grafnot-store-v2 + schemaVersion 5, migrate() до v5, связи по id, графы graph.noteIds, профили grafnot-profiles-v1 (изоляция стора и префов, миграция legacy). Нет: срока корзины 30 дней, бэкапа/импорта всего стора, файлового Vault, sync/CRDT, config/*.md, лицензии.
- Шелл: Ctrl+K топ-7 (kind=prompt), сайдбар-рейл + правая панель + Alt+0, Ctrl+Alt+N, темы, RU/EN/KZ, тосты max 3 / 2600 мс, настройки (тема/язык/лимит), шторка «Ещё» на мобиле.
- Гейты: JS gzip 224.3/240 КБ (93%), warning Vite 500 КБ (raw ~737 КБ), 127 unit + 61 e2e, oxlint 0 но в CI не гоняется, check:i18n (остатки ~50 mock-ключей).

2. АНАЛОГИ — ЧТО БЕРЕМ КАК ПЛАНКУ
F1 Obsidian (CA/US): владение данными К1, отказоустойчивость К3 (автообновление ссылок, сироты, undo), скорость К4 (поиск 10k <200 мс, граф без лагов). У Grafnot сейчас: К1 частично (localStorage, но без файлов/экспорта всего), К3 частично (связи по id + каскад, но без истории версий), К4 не доказан (поиск O(n) без memo, граф синхронный).
F2 Notion (US): нулевой порог К6, чистый старт, шаблоны в 1 клик. Grafnot близко: пустой старт + 1 хинт, первая связка <2 мин по ТЗ, но Pro-замок 20 без превью роняет К6 (JourneyMap low 2/5).
F3 Roam (US): networked thought, daily notes, двусторонние ссылки. Grafnot: входящие есть, диалога «A ↔ B» достаточно, но нет daily notes и обратных ссылок в тексте.
F4 Logseq (AGPL): открытость, Git-история, local файлы. Grafnot: кода открыт внутри вуза, но формат — JSON в localStorage, не файлы; истории нет.
F5 Anytype (DE): local-first + sync (CRDT). Grafnot: local-first без sync вообще; статус «Сохранено локально» честный, но перенос на другое устройство = ручной экспорт одной заметки.
K1 Dapter (KZ): forgiving-ввод, живой ответ в gutter, тенге офлайн, трилингва, без аккаунта. Урок: калькулятор Grafnot должен считать прямо в строке, а не отдельным списком блоков; нужен tolerance к «5 яблок».
K2 Bilimland: видео по ГОСО на 3 языках. Урок: привязка заметок к предметам/ЕНТ-шаблонам, а не абстрактные графы.
K3 Platonus: кредиты/GPA/дедлайны. Урок: календарь должен тянуть дедлайны, а не только ручные задачи.
K4 Aitu: суперапп-каша. Анти-урок: не раздувать модули, держать 5 кнопок по умолчанию.
K5 Qalan: адаптивный тренажер. Урок: «похожие/сироты» должны учить, а не просто listar slice(0,3/0,4).

Вывод ниши из README §2.3 сохраняется: никто не совмещает Высокий К1 + Низкий К6 + Высокий К2. Это ТЗ Grafnot.

3. КАК ВЫГЛЯДИТ ЗАВЕРШЕННЫЙ GRAFNOT 1.0
3.1. Продукт для персоны Аружан, 19, phone-first, RU/KZ (JourneyMap.md):
- Первый запуск: 1 кнопка «Создать», мини-маршрут «заметка → задача → связь» за <2 мин без docs, SUS >80.
- Повседневность: конспект + задача со сроком рядом, Ctrl+K находит за 2-3 буквы, календарь-неделя + повестка, карта объясняет структуру курса.
- Возврат через неделю: тот же профиль, полный бэкап/восстановление в 2 клика, перенос на ноутбук без потерь.
- Честность: везде где семпл — бейдж «sample», где локально — «только на этом устройстве + бэкап», никаких фейк-синков.

3.2. Функционал Done:
- Notes: WYSIWYG + картинки/таблицы, импорт/экспорт папки .md 100% контента и >=95% связей, история версий (v-просмотр + откат), корзина 30 дней с авточисткой и счетчиком дней.
- Links: диалог с поиском по title+text, топ-20 + пагинация, входящие/исходящие в обеих заметках, экран «Битые» с починкой, доля сирот <5% на тестовом корпусе.
- Tasks: повторы (ежедневно/еженедельно), напоминания (если Tauri/PWA позволяют), Kanban «Текст/Канбан/Календарь 1 кнопкой», приоритеты, фильтр по графу/заметке.
- Calendar: неделя + месяц + повестка дня, drag задачи по дням, не-ISO = «Без даты» с явным бейджем.
- Map: realtime-физика с паузой, миникарта, фулскрин, фильтры (сироты/граф/тег), кластеры, открытие узла с клавиатуры, perf: 1000 узлов интерактивно, 10k поиск <200 мс (замер в e2e).
- Prompts: реальный словарь 2000+ тегов с частотами + атрибуция Danbooru, попарная совместимость, живые N в UI только при бэкенде/дейта-пайплайне, иначе честный «static <дата>». LLM-шаблоны: fill&copy в 1 клик с тестом буфера, привязка переживает удаление заметки (tombstone, а не молчаливое исчезновение).
- Profiles/Data: файловый Vault (Tauri File System Access) + localStorage как кэш, полный export/import JSON .zip, квоты с понятным диалогом, config/*.md для G2-P3, лицензия MIT/AGPL выбрана.
- Shell/UX: единые лимиты без «скрытого» контента (лимит + счетчик «показано X из Y»), пустые состояния с CTA везде, модалки с Esc/trap/возвратом фокуса, тосты с очередью и доступным таймингом, мобильный таббар 5 кнопок + «Ещё» с картой и промптами без потери контекста, кнопка панелей только там где панели есть (Home), a11y: все иконки с tr-aria, контраст TagDot по теме, удаление везде через один arm-confirm.

3.3. Архитектура Done:
- App.tsx <600 строк: только композиция; стор-действия в features/notes|tasks|graphs|prompts, хранение в storage/, UI-примитивы в ui/.
- store.ts разбит: types.ts + migrate/*.ts (по версиям, с ветвлением по schemaVersion) + repo (load/save/backup) + selectors (memo). Нет мутабельных глобалов типа migrationDropped.
- id через crypto.randomUUID + счетчик, без Date.now() коллизий. Сохранения debounced (300-500 мс) + бэкап last-good + журнал.
- Поиск индексированный (inverted index + useMemo/worker), граф в worker + canvas при >500 узлов, списки виртуализированы.
- Ключи строго grafnot-<name>[:<profileId>], bare только legacy-миграция. i18n только tr('key') x3, fallback «—» + лог, 0 dead keys.
- Code-splitting: Tiptap + d3 в lazy-чанках, старт <150 КБ gzip initial, warning 500 КБ закрыт.

3.4. Качество Done:
- Unit >=200 (ядро + миграции всех версий + селекторы), e2e >=90 (включая экспорт/импорт, quota, мобильный замок, темы/языки, fill&copy), perf-бюджет в CI, oxlint в CI, check:weight <200 КБ initial.
- Доки в sync: оба README (числа/байты/гейты) генерируются скриптом, JourneyMap валидирована интервью (не гипотеза).

4. ПРОЦЕНТ ГОТОВНОСТИ (оценка на 02.10.2026)
- От полностью завершенного продукта 1.0 выше: ~48%.
  Notes 70 / Tasks 60 / Calendar 50 / Map 55 / Prompts 35 / Data-Profiles 60 / Shell-i18n-a11y 60 / Tests-Gates 60 / Docs-Diploma 65. Среднее ~57, минус 9 за архитектурный долг (God-App, sync-граф, O(n) поиск, вес 93%) = 48.
- От дипломного MVP (без CRDT/sync, без Tauri обязательно): ~68%.
  Закрыто ядро и честность (связи по id, migrate, e2e в репо). Не хватает: словарь 57→2000+, корзина 30 дней, история версий, Kanban, полный бэкап, perf-доказательства 10k, SUS-замер.
- До «можно показать как Obsidian-альтернативу»: не хватает файла-Vault, импорта/экспорта всего и истории. До «можно пользоваться семестр»: не хватает бэкапа, напоминаний и мобильного входа без шероховатостей.

5. ДОРОГА К 100% (порядок)
1) Бэкап/импорт всего стора + срок корзины (снимает страх потери — Journey low 2/5).
2) Реальный словарь тегов + атрибуция (промпты из демо в фичу).
3) Code-splitting + индекс поиска + worker графа (perf и вес).
4) Vault-файлы (Tauri) + config/*.md + лицензия.
5) История версий + Kanban + месяц-календарь.
6) Разбивка App/store + убить Date.now/migrationDropped/bare-ключи.
7) A11y-проход (Esc/trap/focus, контраст, aria x3) + консистентные пустые/лимиты/arm-confirm + перенос кнопки панелей в Home.
8) SUS/время/сироты замер Lab4 + sync README скриптом + CI (oxlint/weight/i18n/e2e).
CRDT-sync — только после 1-8.

Критерий стопа: первая связка <2 мин, сироты <5%, поиск <200 мс на 10k, SUS >80, экспорт 100%/95%, вес initial <200 КБ, 0 dead i18n, e2e зеленые на preview и на Tauri-сборке.
