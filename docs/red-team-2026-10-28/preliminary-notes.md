# Предварительная оценка — 2026-10-28
Ограничение: основной исследователь случайно увидел фрагмент первого отчёта при чтении входных файлов. Поэтому этот документ НЕ заявляется слепой baseline. Два отдельных агента исследуют код/тесты без отчёта.
До полного чтения отчёта проверено:
- IA: заметки, план (список/неделя), карта, промпты, настройки; локальные профили, Tiptap и граф связей.
- Показанная заметка зависит от route.param; мутации от activeId. Живой сценарий в отдельном origin 127.0.0.1:59177: Alpha→создать Beta→Back→ввод в Alpha заменил тело Beta содержимым Alpha; при открытии Beta это видно в редакторе. Исходное Beta initial body исчезло.
- Глобальная кнопка + Новая заметка сначала открывает палитру, затем нужно выбрать команду; первый экран пустой заметки не переводит фокус в заголовок.
- Поиск списка использует title + первые PREVIEW_LEN символов text; проверка поиска хвоста ещё впереди.
- Модель linkedIds отделена от текста; pickSuggest удаляет [[query и добавляет связь; inline-ссылка в документе не остаётся.
- Слой сохранения явно учитывает dirty, blocked/conflict/failed, raw-base, профили и миграции. Большой App сам по себе не основание для переписывания.
- Главная рабочая гипотеза: сначала надёжность адресации/обратимости и переносимость, затем исследование пользовательского ядра. Аудитория из интерфейса не выводится.
