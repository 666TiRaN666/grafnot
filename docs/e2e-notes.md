# E2E: известные грабли

Вход — `e2e/check6.cjs` (`npm run e2e`, порядок групп), обвязка — `e2e/harness.cjs`, счётчики (`EXPECTED_CHECKS`, `GROUP_SIZES`) — `e2e/manifest.cjs`, проверки — `e2e/groups/<группа>.cjs`. Для правки читать только файл нужной группы. Часть групп: `GROUPS=G19-notes,G20-plan`. Новая группа: файл в `groups/`, имя в `ORDER` и `GROUP_SIZES` (самотест раннеров требует точного совпадения); хелпер, нужный нескольким группам, — в `API` обвязки. `VERBOSE=1` — подробный вывод, `E2E_FIXED_CLOCK=ISO` — замороженные часы, `E2E_TRACE=1` — трассировка Playwright.

- Консоль PowerShell искажает казахские глифы — сверять только через ASCII-дампы или файлы UTF-8.
- Фокус после синтетического клика: ждать `waitForFunction` на `document.activeElement`.
- Значение инпута читать после ре-рендера; фокус может уйти в radio.
- `getByRole({ name })` — полное совпадение без учёта регистра: суффиксы вроде `(0)` ломают поиск.
- Сиды, пишущие `grafnot-store-v2`, обязаны сбрасывать `grafnot-profiles-v1`, иначе миграция не запустится; учитывать миграцию графов.
- reseed/resetStorage чистят и hash: reload его сохраняет, иначе тест стартует не с того раздела.
- Строки за пределом порции списка (50) невидимы — сначала поиск по списку, потом клик.
- Выбор из палитры: ждать смены hash и свежего заголовка (редактор перемонтируется).
- Геометрия карты — только после сброса вида (`waitForFunction` на identity-transform), иначе клик по устаревшему transform промахивается.
- Сиды для проверок выделения кладут текст в tiptap `content`: поле `text` редактор не рендерит.
- Проверки отсутствия по `hasText` — только точным совпадением заголовка (`/^Title$/`), иначе дата в мете даёт ложные совпадения (`Seed 2` ↔ `Seed 20`).
- Ctrl+Alt+T — нажимать клавишами, не кнопкой.
- Lazy-чанки (неделя, настройки, контекстная панель) монтируются с задержкой: считать элементы только после появления контейнера.
- Undo-тосты живут 8 с и могут перекрывать друг друга между проверками — ограничивать локатор нужным тостом.
- Состояние ждать одним условием, не читать один раз (05.11.2026, гонки, которые таймингом скрывала Windows и проявил Linux): фокус после Enter в заголовке (Tiptap ставит его на следующем кадре), фокус новой заметки (редактор монтируется после строки заголовка), статус «Сохранено» (второе чтение попадает на новое сохранение), подпись кнопки после смены маршрута (прежний конструктор ещё смонтирован).
- Щелчок по разделу в навигации: `location.hash` меняется сразу, `hashchange` и перерисовка — позже, а вход в раздел сбрасывает его поиск. Перед вводом ждать hash и два кадра.
- Кнопка, которая перезагружает страницу (`registry-retry`): щёлкать вместе с `waitForEvent('load')`, иначе следующий шаг может выполниться до перезагрузки.
- Кириллическая раскладка: `e.key` = «л» для K. Проверять синтетическим `KeyboardEvent` с `key` и `code`; приложение сверяет буквы и по `e.code`.
- Новая заметка (`newViaPalette`): поле заголовка предыдущей заметки ещё смонтировано, когда меняется hash. Ждать пустой заголовок и фокус в тексте новой заметки, иначе ввод в заголовок попадёт в старую или будет сброшен.
- P12 zoom+drag: после смены графа камера ещё вписывает новый граф — исходный масштаб читать, когда `transform` держится 300 мс (причина прежней нестабильности P12 из README «Долги»).
