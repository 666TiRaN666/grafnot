# Промпты и планы Grafnot

## Актуальное поручение

[Редизайн и перепроектирование: «Спокойное рабочее пространство»](actual/Grafnot_Redesign_Prompt.md).

Цель — личная база знаний для широкой аудитории. Приоритет — компьютер; на телефоне основные сценарии имеют собственную полноценную компоновку. Изменения навигации выбирает владелец после предложения; граф, промпты, вычисления и их данные сохраняются. Исследование и макеты не ждут завершения технических пакетов.

Результат этапа 1 (29.10.2026): [фактическое состояние и предпроектное исследование](Grafnot_Stage1_Research_2026-10-29.md), снимки — `stage1-2026-10-29/`.

`actual/` содержит актуальные промпты и планы поручений. Нахождение здесь не означает разрешения выполнить все этапы: границы запуска указаны внутри документа. Известные дефекты и необходимые оговорки сведены в самом промпте; старые аудиты не являются обязательным входом.
