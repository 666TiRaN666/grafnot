=== ЦЕЛЬ И НЕ-ЦЕЛИ ===
Цель: переработать интерфейс ВСЕХ страниц с нуля ради эргономики: минимум движений курсора и кликов, крупные и близкие цели, предсказуемая навигация. Старые UI-паттерны не сохраняются, если не проходят «Нормы» ниже. Сохранять проделанную UI-работу ради неё самой запрещено.
Неприкосновенно (это не UI): store.ts (схема, migrate, LoadResult), profiles.ts, storage/profileBoot.ts, конвейер сохранения (flushSave, saveState, lastSeenRaw, баннеры blocked/conflict/failed), exportRaw, логика ErrorBoundary, i18n x3 + check:i18n, бюджеты веса. Меняется только их внешний вид и место показа. Новые персистентные настройки UI только аддитивно через prefs/listPrefs с ключами по профилю.
Регрессионные e2e-группы по находкам A1–B10 (P29–P36 и др.) ПЕРЕЖИВАЮТ редизайн: меняются селекторы, смысл теста нет.

=== НОРМЫ (применяются к каждому этапу, проверяются в S12) ===
N1 Размеры целей (закон Фиттса):
 - touch (@media (pointer: coarse)): ≥ 44×44 CSS px; mouse: кнопка с текстом ≥ 32 px по высоте, иконочная ≥ 36×36. Визуально можно меньше, область попадания расширять padding или ::after.
 - Зазор между соседними целями ≥ 8 px; между основным и деструктивным действием ≥ 24 px и они не в одном ряду.
 - Вся строка или карточка списка = цель открытия (≥ 44 px на touch, ≥ 40 на desktop); внутри неё отдельные цели (чекбокс, «⋯»).
N2 Позиция:
 - Действие рядом с объектом: попап привязан к триггеру. Центрированная модалка только для необратимых подтверждений и блокирующих ошибок.
 - Основная кнопка формы в конце вертикального потока: на mobile во всю ширину и sticky снизу, на desktop справа внизу; «Отмена» слева.
 - Края и углы: навигация у левого края (rail) / нижнего (tab bar), «Создать» в верху rail, на mobile центральная «+» в tab bar, зона большого пальца = нижние 40% экрана.
N3 Ввод: поля вертикально, label над полем, автофокус на первом, Enter подтверждает, Esc отменяет, Tab-порядок = визуальный. Никаких существенных действий, доступных только по hover.
N4 Обратимость: удаление выполняется сразу + Undo-тост 8 с (крупная кнопка). Подтверждение (ConfirmDialog) только для необратимого: очистка корзины, удаление профиля.
N5 Хик: ≤ 7 пунктов в группе, редкое в «⋯», прогрессивное раскрытие, последний выбор запоминается.
N6 Отклик: визуальная реакция ≤ 100 мс, оптимистичные обновления, у каждого пустого состояния одно понятное основное действие.
N7 Клавиатура: «/» фокус поиска страницы, Ctrl+K палитра, N новый элемент страницы, Ctrl+Enter главное действие формы, стрелки по спискам, Delete с Undo.
N8 Доступность: контраст ≥ 4.5:1 в обеих темах, видимый фокус, смысл не только цветом, aria-имена на каждой иконочной кнопке, prefers-reduced-motion.
N9 Списки: без селектора лимита. Автодогрузка/виртуализация порциями по 50, строка «Показано X из Y», один переключатель плотности в «⋯» списка (где списки длинные).
