## Требует человека

Это нельзя сделать или честно проверить отсюда.

1. **Настоящий телефон** (Android и iPhone): экранная клавиатура и прокрутка к каретке, казахский IME, системная кнопка Back, свайп нижних листов, новая шапка «← Назад». Всё выше — эмуляция Chromium.
2. **Живые люди**: [протокол из 5 участников](Stage6_Review.md#7-протокол-проверки-с-людьми-предложение). Фокус-группа 29.10 была модельной (субагенты), не исследованием с людьми.
3. **Windows**: `npm run gates -- --e2e` после этих изменений не запускался (на Linux зелёный). Посмотреть шрифт Segoe UI: высоту полей, иконки, перенос KZ-строк.
4. **Настоящие Firefox и Safari**: возврат панели W9 проверен в Chromium со скрытым API; порядок событий `storage`/`pagehide` (D10) — только Chromium. Firefox и WebKit для Playwright можно скачать (~100 МБ каждый) и прогнать smoke — только с вашего разрешения.
5. **Решения владельца**:
   - Язык текста встроенных промптов: следовать интерфейсу или выбирать отдельно (как язык файла у навыков). Сохранённые промпты хранят значения по именам полей, поэтому перевод текстов требует решения о совместимости.
   - Новая заметка: пустой заголовок и фокус в тексте (W6) — трое участников фокус-группы ждали фокус в заголовке.
   - Подписи на карте сокращаются до 14 знаков (полное имя — при наведении и выделении).
   - «+ Задача» из заметки берёт выделенный текст или имя заметки; срок — через тост «Указать срок».
   - После восстановления из корзины страница корзины остаётся открытой — проверить на людях (протокол H4).
   - Слияние версий при конфликте вкладок: в D10 в 37 из 40 конкурентных прогонов одна правка ждала ручного выбора.
6. **Коммит, push и слияние в `main`** — только по вашей команде. `main` на GitHub стоит на первом коммите, вся работа в ветке `redesign-s0-s13`.

Долги вне рамок редизайна (README «Долги»): история версий заметок, экспорт всей рабочей области одним файлом, слияние конфликтов вкладок.
