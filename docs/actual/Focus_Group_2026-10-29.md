## Блокирующие и риск потери данных

1. **Связь `[[…]]` вырезается из текста заметки** (Марат, подтвердила Аружан): «Опирается на [[X]], проверяется в [[Y]]» → «Опирается на  проверяется в».
2. **Печать без курсора в тексте теряется и срабатывает как горячие клавиши** (Sofia): открыла заметку из списка, начала печатать — создалась новая заметка, текст пропал.
3. **Переименование профиля по Enter создаёт новый профиль** и переключает на него (Ерлан, проверено дважды, RU и KZ).
4. **«В заметку ▾» открывается за краем экрана** на планшете, привязать промпт к заметке нельзя (Камила); меню «⋯» заметки уходит за левый край на телефоне (Аружан).
5. **Перестановка тегов недоступна на касаниях** — только Alt+стрелки (Камила).
6. **Неверный синтаксис SDXL**: каждый тег в `(tag)` → весь промпт ×1.1, с весом `(((x)))` (Камила).

## По разделам

- **Заметки:** счётчики связей не сходятся (список / кнопка / шапка); «+ Задача» из заметки без срока и без своего названия; перед текстом на телефоне 4 ряда кнопок.
- **План:** выбранный срок «прилипает» к следующей задаче; окно задачи озаглавлено «Новая задача…» для существующей.
- **Карта:** перетащенная заметка пружинит обратно (сохраняется только закреплением); подписи обрезаны, стрелки по тексту; графы создаются без имени, «Добавить в граф» нет в меню заметки; кнопки «5/10/25/50» без подписи.
- **Промпты:** язык SKILL.md смешивается с языком интерфейса; AGENTS.md молча теряет «Когда применять»; нет Ctrl+S; копия встроенного навыка с тем же именем; правки встроенного «Арт: персонаж» пропадают без предупреждения; вес только из трёх ступеней; Flux — не естественный язык; результат картинки далеко от редактора.
- **Корзина:** на телефоне спрятана в меню ◔; после восстановления уводит из корзины.
- **Настройки:** поле переименования профиля пустое и без фокуса; восстановленный профиль получает имя файла и русский язык.
- **Клавиатура:** `N`, `/`, `Esc`, стрелки работают по-разному в разных разделах; справка неполная.
- **KZ:** дни недели по-английски (Mon…), заголовок «2026 M10», «дерегі: …» слито с названием.
