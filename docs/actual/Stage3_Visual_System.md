Дата: 29.10.2026. Поручение: [план-промпт](Grafnot_Redesign_Prompt.md), этап 3. Модель и сценарии: [Stage2_Model.md](Stage2_Model.md). Пилот: [`../stage3-pilot/pilot.html`](../stage3-pilot/pilot.html), снимки — [`../stage3-pilot/shots/`](../stage3-pilot/shots/).

Статус: владелец выбрал вариант **A «Лист»** и подтвердил рекомендации пилота (29.10.2026). Система описывает целевой вид; приложение не менялось. Дефекты D1–D10 этим документом не закрываются.

Пометки: **[Решение]** — принято владельцем; **[Правило пилота]** — следует из измерения в пилоте, обязательно для реализации; **[Решение пилота]** — рекомендация пилота, подтверждённая владельцем 29.10.2026; **[Пилот ≠]** — значение отличается от показанного в пилоте, с причиной.

## 1. Принцип варианта A

- Всё приложение — **одна поверхность** (`--u-card`). Навигация, список, редактор, закреплённая панель и детали задачи различаются вертикальными линиями `--u-line`, отступами и типографикой, а не фоном и рамками.
- **Цвет — только по роли:** акцент отмечает выбор, ссылку, основное действие и фокус; предупреждение — просрочку и ошибку сохранения. Заголовки, бейджи и иконки разделов акцентом не красятся (кроме иконки активного раздела).
- **Возвышение — только у временного:** временная панель, меню, нижний лист и карточки недели (перетаскиваемые объекты). Постоянные области тени не имеют.
- **Рамки — только у элементов управления** (кнопки, поля, чекбоксы). Строки списков, заметка, панель и группы задач рамок не имеют.

Снимки варианта A: `01-A-notes-1440.png`, `04-A-notes-1440-dark.png`, `07-A-plan-1440.png`, `18-A-panel-temp-1280.png`, `27-A-m-list.png`. Остальные снимки показывают те же компоненты в вариантах B/C; размеры, текст и состояния совпадают, отличаются только фоны областей.

## 7. Иконки

- Существующий компонент `Icon` (`src/widgets.tsx`): контурные, viewBox 24, `stroke="currentColor"`, скругления. Размер в системе — 18 px (сейчас по умолчанию 19), толщина 1.7–1.8.
- Цвет наследуется: `--u-muted` в неактивных пунктах, `--u-accent` в активном пункте навигации; иконки не несут смысла сами — рядом подпись или `aria-label` (N8, i18n ×3).

## 9. Компоненты

- **Навигация:** «Свернуть» (иконка) → «+ Новая заметка» (`--u-accent-soft`, текст `--u-accent`, 600) → «Поиск Ctrl K» → разделы → пустое место → статус сохранения → Настройки → профиль ▾. Счётчик раздела — числом `--u-muted`, без бейджа-заливки.
- **Строка списка заметок:** заголовок, сниппет, дата; без рамки и без «Связанное: N». Плотный режим — заголовок и дата в одну строку, сниппет в одну строку (режим не выбран, §11).
- **Шапка заметки:** панель инструментов (дата слева; «Вставить ▾», «⋯», «Панель» справа) → заголовок → блок контекста: «Связи: имя · имя · ← имя · ещё N · В графах: чип» + «Все связи» → «Задачи N», «Промпты N» → линия.
- **Кнопки:** обычная — контур `--u-border`, фон `--u-card`; тихая — без контура; основная — `--u-accent`/`--u-on-accent` (только одно основное действие на экран); иконочная — 36×36.
- **Поле ввода:** контур `--u-control`, иконка слева, подсказка клавиши справа (`<kbd>` с контуром `--u-border`).
- **Контекстная панель:** вкладки → «Закрепить», «Закрыть» → содержимое разделами (подписи 12.5/650 `--u-muted`), без карточек внутри.
- **Вычисления:** заголовок раздела + «Добавить»; строка: имя · выражение (моно) · «= результат» (600, табличные цифры).
- **План, список:** подписи групп (просрочено — `--u-warn`), строки задач без рамок: чекбокс · текст · чипы срока и источника; детали справа отдельной областью через `--u-line`.
- **Неделя:** «Входящие» + 7 дней, колонки через `--u-line`, сегодня — `--u-accent-soft`, задачи — карточки `--u-card` + `--u-shadow-row`.
- **Mobile:** шапка (назад / раздел, статус, поиск, профиль) с линией; блок контекста — одна группа кнопок «Все связи · Задачи · Промпты · Вставить»; tab bar с подписями, «+» — круг `--u-accent` 36 px и подпись действия `--u-accent`; полоса дней недели прокручивается внутри.

## 10. Правила, найденные пилотом

1. **Закрепление панели — по оставшейся мере, а не по ширине окна.** [Решение пилота] Закрепить можно, если колонке текста остаётся ≥ 560 px (16 px текста ≈ 65–70 знаков). Эквивалент: окно ≥ 1484 px при навигации с подписями, ≥ 1324 px при свёрнутой. Порог 1440 px из модели не подходит: при нём тексту остаётся 516 px (`15-B-panel-pin-denied-1440.png`, `16-B-panel-pinned-1440-mininav.png`). Иначе кнопка «Закрепить» недоступна с объяснением, панель временная.
2. **Вкладки панели не обрезаются.** [Правило пилота] Если подписи (KZ «Байланыстар · Тапсырмалар · Промпттар») не помещаются рядом с «Закрепить/Закрыть», кнопки переносятся строкой выше (`flex-wrap: wrap-reverse`), `22-C-kz-1440-dark-pinned.png`.
3. **Числа не переносятся внутри.** [Правило пилота] Группы разрядов — узкий неразрывный пробел U+202F; результат вычисления — `white-space: nowrap` (было «45 / 000» при 1024 px).
4. **Неделя в узком окне.** [Решение пилота] При 1280 px и навигации с подписями колонка 132 px рвёт обычные слова по буквам (`11-B-week-1280.png`); `hyphens: auto` в Chrome/Windows не помогает. Решение: колонка ≥ 150 px с горизонтальной прокруткой внутри недели (не страницы).
5. **Узкое окно — навигация свёрнута по умолчанию.** [Решение пилота] Чтобы тексту оставалось ≥ 560 px без панели, навигации с подписями нужно окно ≥ 1164 px. Решение: ниже ~1200 px навигация по умолчанию свёрнута, если пользователь явно не развернул (`25-B-notes-1024-full.png` — тексту 420 px; `26-B-notes-1024-mini.png` — 580 px).
6. **Графы — в двух местах.** [Решение пилота] Чип «В графах: …» в блоке контекста (видно без панели) и переключатели членства во вкладке «Связи».
7. **Границы элементов управления ≥ 3:1.** [Правило пилота] Отдельный токен `--u-control`; `--u-border` остаётся для декоративных контуров.
8. **Длинные имена.** Заголовок строки списка и источник задачи — многоточие с полным именем в доступном имени; заголовок заметки и задачи в деталях — перенос, без обрезки (`21-B-kz-1440.png`, `35-B-m-kz.png`).

## 11. Не выбрано

- Плотность списков: система описывает обычную; плотный режим показан в пилоте (`23-…`, `24-…`) и может стать настройкой отдельным решением.
- EN-строки, реальное устройство с экранной клавиатурой, reduced motion и клавиатура — проверяются при реализации (пилот статичен).

## 12. Движение

- Длительности — существующие `--u-d1` 120 ms (наведение, нажатие), `--u-d2` 180 ms (появление временной панели, меню, листа: `transform` + `opacity`). `prefers-reduced-motion` → 0 (уже в `tokens.css`).
- Анимация не задерживает ввод и сохранение; повторное нажатие прерывает её.
