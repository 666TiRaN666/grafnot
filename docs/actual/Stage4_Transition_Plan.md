## 3. Существенные решения: адаптация или замена

| Вопрос | Адаптация | Замена | Выбор и причина |
|---|---|---|---|
| Текущая заметка (D1) | ID из маршрута передаётся в действия явно; `store.activeId` остаётся сохраняемой «последней открытой» и синхронизируется из маршрута | Удалить `activeId` из `Store` | **Адаптация**: замена ломает схему (не аддитивна), `activeId.test.ts` и посадку при запуске; адаптация меняет только `App.tsx`/`NotesView` |
| Undo (D2) | Тосты `notifyAction` фиксируют профиль, эпоху сессии и явные ID | Перейти на `ui/useUndo` (одна активная запись) | **Адаптация**: `useUndo` меняет поведение N4 (несколько тостов) и тесты G20/G21/G26; он не подключён («Not connected to any page yet», `ui/useUndo.ts:55`) — удалять отдельно, не в этом пакете |
| Связи при удалении (D3) | Отдельная аддитивная запись `trashMeta: Record<noteId, { incoming: string[]; graphs: string[]; at: number }>`, `SCHEMA_VERSION 7` | Поле в `Note`; снимок соседних заметок | **Отдельная запись**: `Note` уходит в экспорт `.md`, палитру и сохранения; снимок соседей откатывал бы их правки (запрещено D3) |
| Состояние панели и навигации | Новые prefs: `grafnot-ctx:<id>` (`closed`/`pinned`), `grafnot-side-mode:<id>` (`auto`/`open`/`closed`) | Переинтерпретировать `grafnot-right`/`grafnot-side` | **Новые ключи**: старые пишутся при каждом монтировании (`App.tsx:294-300`) и не отличают явный выбор от значения по умолчанию |
| Вставка промпта (7.8) | Новый компактный `PromptInsert.tsx` (lazy) на существующих `workbenchModel`/`promptUtils` | Встроить `PromptWorkbench` | **Новый компонент на старых моделях**: рабочая область — страница с маршрутом, копированием и сохранением; встраивание тянет её состояние в заметку |
| Контекстная панель | Вынести из `NotesView.tsx` в lazy `NoteContext.tsx`, вкладки 5 → 3 | Переписать `NotesView` | **Вынос**: уменьшает чанк `NotesView` (129 КБ gzip, этап 1), правки локальны |
| Выделение на карте (7.7) | Маршрут `#/map/note/<noteId>` + существующий `#/map/<graphId>` | Query-параметры в hash | **Сегмент пути**: `parseRoute` уже сегментный (`router.ts:14-32`), ID графов начинаются с `g` и не совпадают с `note` |
| Поиск палитры (D6) | Поле `haystack` (полный текст) отдельно от `sub` (превью) + «ещё N» | Отдельный индекс | **Адаптация** чистой модели `paletteModel.ts`; семантика AND-токенов сохраняется |
| Автооткрытие профиля | Решение в инициализации `App.tsx:96-98` по `registry.activeId` при статусе реестра `ok` | Изменить `profileBoot.ensureRegistry` | **Адаптация в App**, `profileBoot.ts` не трогать; если окажется нужным — отдельное согласование |

Фреймворк, хранилище (localStorage) и формат данных не меняются; единственное изменение схемы — аддитивное `trashMeta` (W4).
