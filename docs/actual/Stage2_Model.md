## 1. Принципы модели

1. **Текущая сущность — то, что показано.** Заметку на экране определяет маршрут `#/notes/:id`. Команды, вычисления, экспорт, Undo и вставки адресуются этому ID, а не отдельному `activeId`. [Сейчас] экран читает route (`src/App.tsx:1213`), команды — `activeId` (`src/App.tsx:492, 856, 905, 920, 1016`) — D1.
2. **Контекстная операция запоминает цель.** Undo, вставка промпта, создание задачи из заметки фиксируют профиль, сущность и сессию в момент запуска и при выполнении проверяют их актуальность. Неактуальная операция ничего не записывает и сообщает об этом.
3. **Содержимое в центре.** Навигация и контекст подчинены редактору; контекстная панель не сжимает текст постоянно.
4. **Результат виден на месте действия.** Связи, задачи и промпты заметки обнаруживаются в самой заметке подписанными входами, а не только счётчиками.
5. **Данные сохраняются.** Граф, промпты, вычисления, заготовки, «Похожее» и их данные остаются; меняется только размещение. Схема хранилища — только аддитивно.

## 4. Экран заметки

### 4.1 Шапка и компактный блок контекста

```
Идеи для курса HCI                                [Вставить ▾]  [⋯]
Связи: Встреча с куратором · ← Список литературы · ещё 2   [Все связи]
[Задачи · 1]   [Промпты]
```

Заметка без связей:

```
Без названия
Связей пока нет                                      [Все связи]
[Задачи]   [Промпты]
```

- Блок связей [Решение] показывает **названия** связанных заметок (исходящие и входящие вместе; входящая помечена «←» и в доступном имени «ссылается сюда»), до 3 названий + «ещё N», и подписанную кнопку «Все связи». Название — ссылка на заметку.
- Членство в графах [Предложение]: последняя позиция блока или первая строка во вкладке «Связи» («В графах: Курс HCI»). Выбор места — на пилоте; данные — существующий `Graph.noteIds`.
- «Задачи» и «Промпты» [Решение] — отдельные подписанные кнопки, видимые всегда (и при 0 элементов, и у заметки без связей). Счётчик добавляется к подписи, если элементов > 0. Каждая открывает панель на своей вкладке.
- «Все связи» при отсутствии связей открывает «Связи» с «Предложениями» — путь к первой связи.
- Блок не дублирует полную панель: при закреплённой панели он остаётся (без скачка раскладки), активная вкладка отмечена на соответствующей кнопке.

### 4.2 Меню «Вставить»

[Решение] Видимая кнопка «Вставить ▾» в шапке редактора; «/» остаётся быстрым дополнительным способом с тем же набором.

| Пункт | Действие | Фокус после |
|---|---|---|
| Заготовка ▸ Лекция / ЕНТ / Проект | Вставка шаблона в позицию курсора (как `insertTpl`) | Курсор в первом поле заготовки |
| Промпт… | Выбор и заполнение промпта без ухода из заметки (§7.8) | Поле поиска промпта |
| Вычисление | Добавляет вычисление в показанную заметку; блок появляется | Поле имени вычисления |
| Ссылка на заметку | Открывает поиск `[[` у курсора | Поле поиска заметки |

Меню доступно с клавиатуры (стрелки, Enter, Esc с возвратом фокуса в редактор) и на touch (на mobile — нижний лист).

### 4.3 Вычисления

[Решение] Блок вычислений показывается только при `calcs.length > 0`. Добавление — через «Вставить» или «/». Удаление последнего вычисления скрывает блок; удаление — сразу, с Undo (норма N4) [Предложение: сейчас `deleteCalc` без Undo, `src/App.tsx:1024`]. Данные `calcs` не меняются.

### 4.4 Заметка без заданного заголовка

[Решение] После создания фокус в тексте; заголовок задаётся позже. Безопасное отображение [Предложение]:

- **Хранение.** Пока пользователь не ввёл заголовок, `title` хранится пустой строкой. Отображаемое имя вычисляется и **никогда не записывается** в `title` или текст. Существующие заметки «Новая заметка N» не переименовываются.
- **Вычисляемое имя.** Первая непустая строка текста (обрезанная по длине, с многоточием); при пустом тексте — «Без названия» (i18n ×3). Визуально отличается от заданного заголовка (вторичный стиль), доступное имя: «Без названия: <начало текста>».
- **Различимость.** В списке, палитре и `[[`-подсказке рядом показываются дата/время изменения и фрагмент текста; одинаковые вычисляемые имена допустимы, потому что связи идут по ID (`src/store.ts:12`).
- **Где применяется.** Список, палитра, `[[`-подсказка, блок связей, вкладки контекста, узел карты, чип задачи «из: …», тосты удаления/восстановления, заголовок вкладки браузера, имя файла экспорта (санитизированное; запасной вариант `note-ГГГГ-ММ-ДД`).
- **Редактор.** Поле заголовка пустое с плейсхолдером «Без названия»; в порядке Tab стоит перед текстом (Shift+Tab из начала текста).
- **Поиск.** Находит заметку по тексту (список и `[[` уже ищут по тексту: `src/linkSuggest.ts:8`).
- **Ограничение для этапа 4.** `uniqueTitle` подставляет «Новая заметка» для пустого и требует уникальности (`src/App.tsx:244-251`, комментарий о ссылках по заголовку устарел). Нужно: не применять к пустому заголовку, проверить `migrate()`/валидацию на `title: ''`, экспорт и карту.
- Пустая заметка (без заголовка, текста, связей, вычислений) остаётся обычной заметкой; автоматическая очистка в модель не входит.

## 7. Сценарии

Каждый сценарий: шаги → фокус → результат. «Защищает от» — какие дефекты обязаны быть закрыты до приёмки реализации сценария.

### 7.1 Обычный запуск — последний профиль

1. Реестр читается; `registry.activeId` указывает на существующий профиль → профиль открывается без выбора.
2. Восстанавливается последний маршрут профиля (или активная заметка, как сейчас `src/App.tsx:1161-1166`); фокус не перехватывается.
3. `activeId` отсутствует среди профилей → безопасный выбор профиля (текущий `ProfilePicker`), без автосоздания.
4. Ошибка чтения реестра или стора, повреждение, будущая схема → текущие баннеры blocked/registry-blocked; автооткрытие их не обходит, новый профиль не создаётся.

Защищает от: потери данных при автооткрытии. Технический пакет сохраняет пути blocked/conflict/failed, корректную загрузку реестра и изоляцию сессий (промпт, этап 4).

### 7.2 Редкое переключение профиля через меню

1. Desktop: «◔ Тест ▾» внизу навигации; mobile: «◔» в шапке → список профилей.
2. Выбор → `flushSave` текущего профиля; при неудаче — переключение блокируется с объяснением (как сейчас, `src/App.tsx:620-623`).
3. Все незавершённые Undo и контекстные операции (вставка промпта, создание задачи) старого профиля снимаются явно: тост «Отмена недоступна после смены профиля».
4. Открывается последний маршрут нового профиля; фокус — на основном содержимом.

Защищает от: D2.

### 7.3 Создание заметки

Входы: desktop — «+ Новая заметка», `Ctrl+Alt+N`, `N` в списке; mobile — «+ Заметка»; карта на mobile — «+ Заметка».

1. Создаётся заметка с пустым `title`; маршрут переходит на её ID.
2. Фокус сразу в тексте новой заметки (пустой абзац) [Решение]. Не требуется редактировать «Новую заметку» или нажимать Enter.
3. Заголовок — позже: щелчок по плейсхолдеру «Без названия» или Shift+Tab.
4. Сообщение для скринридера: «Новая заметка создана» (aria-live), без визуального шума.

Защищает от: D7, D1.

### 7.4 Создание из других разделов

См. §6.1. Desktop сохраняет `N` в Плане (новая задача) и «+ Новый шаблон» в Промптах.

### 7.5 Поиск и продолжение

1. `Ctrl+K` / поле поиска в шапке → палитра ищет по полному тексту; группы по 4 строки и «ещё N» для каждой группы.
2. Enter → заметка открывается, фокус в тексте (в начале или у первого совпадения — на пилоте).
3. `/` в списке → фильтр списка с подсветкой; Enter открывает выбранную строку.
4. Сохраняются AND-токены и различие казахских букв.

Защищает от: D6.

### 7.6 Связи в контексте

1. Добавить: `[[` в тексте или «Вставить → Ссылка на заметку» → поиск → Enter; блок связей обновляется сразу. Альтернатива: «Все связи» → «+ Связать» или «Связать» в предложениях.
2. Отвязать: «×» во вкладке «Связи» → связь удалена, тост Undo; Undo возвращает связь **исходной** заметке, даже если пользователь уже открыл другую.
3. Графы: переключатели «В графах» меняют `Graph.noteIds`, с Undo.

Защищает от: D2, D9 (видимость отношений).

### 7.7 Переход к общей карте и возврат

1. «Показать на карте» (вкладка «Связи» или «⋯») → общий обзор карты, заметка выделена и в центре, peek-панель открыта. Промежуточного выбора графа нет [Решение]; граф выбирается на карте существующим селектором.
2. Маршрут кодирует выделенную заметку, чтобы reload/deep link сохраняли выделение [Предложение: формат — этап 4]. Существующий `#/map/:graphId` открывает указанный граф (D8).
3. Возврат «Назад» (браузер, кнопка, `Alt+←`) → `#/notes/:id` той же заметки с восстановлением: прокрутка, курсор/выделение в редакторе, состояние и вкладка контекстной панели; фокус — на «Показать на карте», если панель была открыта, иначе в тексте на прежней позиции.
4. «Открыть» на узле карты → заметка; «Назад» → карта с прежним выделением.

Защищает от: D8, D1.

### 7.8 Промпт из заметки

Входы: «Вставить → Промпт…», «/промпт», вкладка «Промпты» → «Вставить промпт…».

```
┌ Вставить промпт ──────────────────────────────┐
│ [Найти промпт…]                                │
│ Code review · SQL explain · ENT plan · Мои…   │
│ ── Code review ──                              │
│ Язык:  [TypeScript      ]                      │
│ Фокус: [безопасность    ]                      │
│ Предпросмотр: «Проверь код (TypeScript)…»      │
│ [Привязать к заметке]       [Отмена] [Вставить]│
└────────────────────────────────────────────────┘
```

1. Окно открывается поверх заметки (desktop — у редактора, mobile — нижний лист); заметка остаётся на месте.
2. Поиск → выбор → заполнение полей шаблона → предпросмотр → «Вставить» (основное действие в конце, «Отмена» слева — N2). Esc/«Отмена» → ничего не записано, фокус в редакторе на прежней позиции.
3. Image-шаблоны: вставка текущей композиции тегов; редактирование тегов — «Изменить в библиотеке» (явный переход, черновик вставки не создаётся).
4. **Цель вставки** фиксируется при открытии: профиль, ID заметки, позиция курсора, идентификатор сессии/эпохи. Пока окно открыто, позиция сопровождается изменениями документа (маппинг позиций редактора — этап 4).
5. Перед записью — проверка: тот же профиль и эпоха; заметка существует и не в корзине. Если нет — **ничего не записывается**, окно сообщает «Заметка недоступна, промпт не вставлен» и предлагает «Копировать результат». Переход на другой маршрут, смена профиля, удаление заметки закрывают окно без записи.
6. Вставка — обычная правка документа: отменяется `Ctrl+Z` в редакторе; фокус после вставки — конец вставленного текста.
7. **Привязка** — отдельное подписанное действие «Привязать к заметке» (создаёт сохранение с `noteId`, видно во вкладке «Промпты»); не выполняется при вставке неявно. Отвязка — во вкладке «Промпты».
8. Библиотека остаётся местом управления (создание, правка, удаление шаблонов). [Сейчас] из библиотеки результат дописывается в конец заметки по явному ID (`appendToNote`, `src/App.tsx:563`) — это сохраняется как способ «Добавить в заметку…» из библиотеки.

Защищает от: записи в другую сущность или профиль (класс D1/D2).

### 7.9 Добавление вычисления

1. «Вставить → Вычисление» или «/вычисление».
2. Вычисление добавляется в **показанную** заметку (сейчас через `activeId`, `src/App.tsx:1016` — D1); блок появляется, фокус в поле имени; Enter → выражение; Esc → редактор.
3. Удаление вычисления — сразу, с Undo; удаление последнего скрывает блок.

Защищает от: D1.

### 7.10 Задача из заметки и возврат к источнику

1. Выделить текст → «Задача» (меню выделения) или `Ctrl+Alt+T`, или вкладка «Задачи» → «+ Задача из заметки». Задача получает `noteId` показанной заметки.
2. Тост «Задача создана · Открыть»; счётчик на кнопке «Задачи» обновляется.
3. В Плане чип «из: <имя заметки>» → заметка открывается, маршрут и текущая сущность совпадают; «Назад» → План, фокус на той же строке.

Защищает от: D1.

### 7.11 Удаление и восстановление

1. Заметка: «⋯ → В корзину», Delete в списке. Удаление сразу, тост Undo 8 с, привязанный к сущности и профилю (N4).
2. Undo восстанавливает заметку, её входящие связи и членство в графах, не откатывая последующие правки других заметок; выделение и фокус — на восстановленной заметке.
3. После 8 с, reload или смены профиля Undo недоступен явно; восстановление — Настройки → Корзина (mobile: ◔ → Настройки → Корзина) или команда палитры «Корзина» → «Восстановить»; отношения восстанавливаются в объёме, сохранённом при удалении; утраченная история не выдумывается.
4. Очистка корзины — единственное подтверждение (ConfirmDialog, N4).

Защищает от: D3, D2.

### 7.12 Общие правила возврата

- Back/Forward, deep link и reload показывают и редактируют одну и ту же сущность.
- Возврат из Карты, Промптов, Плана в заметку восстанавливает прокрутку, курсор и состояние панели.
- Закрытие временной панели, листа, меню или окна возвращает фокус на вызвавший элемент.

## 9. Будущие критерии приёмки создания и ввода

- После каждого пути создания (§7.3, §6.1) `document.activeElement` — поле ввода новой сущности (текст заметки / поле задачи / первое поле конструктора) в пределах одного кадра после смены маршрута.
- Первый ввод сохраняется в новую сущность по её ID, включая: русскую и казахскую раскладки, IME-композицию (начатую первым нажатием), мёртвые клавиши, вставку из буфера.
- Enter во время IME-композиции не запускает команды; Esc во время композиции её отменяет, не закрывая заметку.
- Два быстрых создания подряд: текст каждой попадает в свою заметку.
- Смена профиля, Back или переход в другой раздел сразу после создания не переносят ввод в другую сущность или профиль.
- Reload после ввода показывает текст в той же заметке; заметка без заголовка отображается по §4.4.
- Mobile: экранная клавиатура появляется на реальном устройстве (где доступно), tab bar не перекрывает поле ввода.

## 10. Польза и переучивание

[Ожидание] — не реализовано и не проверено:
- Запись мысли без промежуточных шагов (фокус в тексте).
- Связи, задачи и промпты обнаруживаются в заметке по подписям, а не через пять вкладок.
- Больше ширины для текста; контекст по требованию.
- Промпт вставляется, не покидая заметку, и не может попасть в чужую заметку.
- Запуск сразу в работу; на mobile доступны настройки и статус сохранения.

Переучить:
- Контекстная панель закрыта по умолчанию (открывается «Все связи» / «Задачи» / «Промпты»).

- Новые заметки без автоматического «Новая заметка N».
- Mobile «+» зависит от раздела (подпись показывает действие); настройки — из шапки.
