## Дифференциаторы и модули


### 1.4. Дифференциаторы от прямых конкурентов

### 1.5. Уникальные модули-фичи

- **G1. Prompt-assist (помощник промптов):** G1a — база image-тегов с индикатором знания модели (градиентный кружок: светлее = лучше; риск помечается отдельно), автодополнение, варнинг рискованных тегов с реальным процентом, синтаксис под модель (Pony — запятые, SDXL — скобки, Flux — естественный язык); G1b — параметризованные LLM-шаблоны («Разбор кода», «SQL-объяснение», «План ЕНТ») с копированием в 1 клик. Сохранения живут в общем сторе (`PromptSave[]`), привязываются к заметкам двусторонне.
P2 «модули-конвейер» (компонентная изоляция Editor|Graph|Tasks|Calendar|Prompt — Search НЕ вынесен в отдельный модуль и живёт в App.tsx, Sync отсутствует полностью как механизм (бэкенда нет); kill-module тест НЕ автоматизирован);

## 2. Конкурентный анализ

### 2.1. Выборка и метод (Lab 1, требование: минимум 2 интерфейса и 5–7 критериев — превышено для дипломного задела)

Иностранные — прямые PKM-конкуренты (класс Second Brain / Linked Notes):

- **F2 Notion** (Notion Labs, США) — эталон all-in-one и низкого порога.
- **F3 Roam Research** (Roam Research Inc., США) — пионер networked thought.

Отечественные (РК) — функциональные аналоги; прямых PKM с графом в РК на 09.2026 НЕ выявлено (включая EdTech-карту и Forbes.kz Топ-30):
- **K1 Dapter** (`dapter.shystud.io`, shy studio / Anuar Shaidenov, Казахстан) — вычислительный блокнот: живой ответ в gutter, forgiving-ввод («5 apples»), именованные значения, тенге офлайн, трилингва EN/RU/KZ, local-first без аккаунта. Ближайший инди-PKM из РК, взят вместо Kundelik.

- **K3 Platonus** (АИС вуза, используется в МУИТ) — кредиты, GPA, прокторинг.
- **K4 Aitu** (BTS Digital / Казахтелеком) — нац. суперапп + AI AiToYou, мини-аппсы.
- **K5 Qalan.kz** — адаптивный тренажёр математики/ЕНТ (репрезентант кластера Daryn.online/Qalan).

### 2.2. Семь авторских критериев оценки (К1–К6 шкала Высокий/Средний/Низкий, К7 — перечислением)

- **К1.** Внутренний локус контроля и независимость данных (no Vendor Lock-in). Происхождение: Шнейдерман + Нильсен + цифровая этика.
- **К2.** Управление когнитивной нагрузкой и архитектура связей (Шнейдерман «снижение нагрузки на память» + Нильсен «распознавание вместо вспоминания»).
- **К3.** Отказоустойчивость при рефакторинге (автообновление ссылок, сироты, версионность/отмена).
- **К4.** Производительность на сверхбольших массивах (поиск на 10 тыс.+ файлов, рендеринг графа).
- **К5.** Масштабируемость функционала и эстетика минимализма.
- **К6.** Порог входа и терминологическая ясность (HEART Adoption + микроскопия).
- **К7.** Уникальные фичи — только проверяемо уникальные в пределах выборки 10 (проверены попарным сравнением, детали — в `Lab1_Grafnot_Report_EN.txt:289-390` и RU-версии).

### 2.3. Выводы по нише

1. Технологическую планку задают Obsidian (К1, К3, К4) и Notion (К6, старт К5).
2. **Разрыв:** ни одна система не совмещает одновременно Высокий К1 + Низкий К6 + Высокий К2. Этот треугольник — ТЗ Grafnot.
3. В РК ниша «казахстанский связный блокнот для учёбы» свободна; Dapter доказывает жизнеспособность local-first трилингвальных блокнотов из РК.
4. Измеримые цели Grafnot: первая связка < 2 мин без docs; доля сирот < 5%; поиск < 200 мс на 10 тыс.; SUS > 80; экспорт 100% контента и ≥ 95% связей.

### 2.4. Таблица Obsidian vs Grafnot (продуктовое обоснование)

| Критерий HCI | Obsidian | Grafnot (улучшение) |
|---|---|---|
| Learnability | Markdown, Vault — неделя обучения | WYSIWYG, пустой старт с 1 кнопкой, первая связка < 2 мин |
| Efficiency | Быстрый для гиков, плагины | Шаблоны «Лекция/ЕНТ/Проект» в 1 клик |
| Error Prevention | Легко удалить vault, битые ссылки молча | Корзина, переименование с обновлением всех ссылок, экран битых |
| Minimalism | 1000+ плагинов, перегруз | 5 кнопок по умолчанию, Pro-режим скрыт до 20 заметок |
| Satisfaction | Утилитарный UI | Эстетика уровня Notion, русский/казахский из коробки |


## 7. Журнал решений

| Решение | Почему так (и что отклонено) |
|---|---|
| React + TS strict + Vite (+ Tauri потом, Electron — нет: 150 МБ+ vs 5–10 МБ) | Экосистема редактора/графа, один код web+desktop+mobile; отклонены Svelte/Vue/Solid (меньше экосистема), Flutter (плох для `.md`/web), Next SSR (лишен для local-first), чистый JS (медленно) |
| Tiptap, не Lexical/голый ProseMirror и не `contentEditable`-хак | React-обвязка, JSON-состояние в стор, undo/redo/вставка/каретка из коробки; ref-хак признан тупиком (undo, вставка, форматирование) |
| d3-force только для физики, рендер свой SVG | Вес +5.4 КБ vs ~300 КБ Cytoscape; DOM-доступность для Playwright; детерминизм через ручные тики |
| Связи по id, переименование O(1), каскад при удалении | Убивает класс висяков; заголовки уникальны только для UI |
| Убить `notebook`, ungrouped по умолчанию | Два источника правды рассинхронизировались (дефект #4); проекция отклонена как новый рассинхрон |
| Отдельный экран задач + `noteId` + чип «из:» | Разделение визуальное, связь в данных двусторонняя |
| Календарь-неделя вместо списка дат | Recognition over recall |
| Явный диалог связей + входящие | Неочевидная кнопка «Связать» и односторонность убиты |
| Пустой старт + 1 хинт | Вместо захламлённых сидов |
| Убить дублирующие табы; Pro-замок честный везде | Навигация одна (сайдбар); табы обходили гейт |
| Рейлы обеих панелей + `Alt+0` (не `Ctrl+0` — занят зумом браузера) + `Ctrl+Alt+N` (с гардом от полей ввода) | Место под текст без drag-resize (отклонён как дорогой и непредсказуемый) |
| Вычисления — список именованных блоков, свой парсер без `eval`, переменные по именам, циклы/unknown — в «—» с тултипом | Прозрачность вместо черного ящика `stipend` |
| Промпты в общем сторе; привязка односторонняя + вычисляемый реверс | Не плодить второе хранилище (урок графов) |
| Семпл-словарь честно помечен, без имитации живости | Живой статистики без бэкенда не бывает |
| Порог риска — константа (распределения нет), синтаксис — презентационный | Не выдумывать наукообразие без данных |
| Один средне-серый outline вместо двух темных/светлых | Математически читается на обоих экстремумах обеих тем |
| `schemaVersion` + идемпотентная `migrate()` | Флаг вместо implicit-триггеров (v5: `trashTasks`) |
| Единый лимит списков (`listPrefs`, один JSON-map) + `useListState`/`useListNav`/`<Hi>`/`useArmConfirm` | Списки дублировали состояние; общие примитивы вынесены, страницы владеют только матчингом и порядком |
| E2E в репозитории (`e2e/`, `npm run e2e`) + `check:i18n` | Сьют жил в Temp без версионирования; dead-ключи ловятся сканером `tr()`-вызовов |


## 10. Приложение А: учебный/дипломный контекст (МУИТ, сжато)

**Норматив:** АО МУИТ, ММ-04,I-01 от 18.11.2020, 29 стр. **Сроки:** темы утверждает кафедра не позднее октября; приказ ректора — до **01.11**; задание выдаётся через 1 неделю после приказа. **Объём:** ≥60 стр. без приложений. **Структура (11 элементов):** обложка; титульник; задание; календарный план; аннотация на 3 языках (каз/рус/eng); содержание; введение ≤2 стр. (актуальность, цель, задачи, объект/предмет, значимость); основная часть (теория: обзор+аналоги+новизна; практика: проектирование, модели, код, эксперименты; опционально экономика) — каждый раздел с введением и выводами, с новой страницы; заключение ≤1 стр.; список литературы IEEE в порядке появления (`[1]`); приложения (прототипы, код, схемы).
**Оформление:** A4, 1 интервал, Times New Roman 14; поля 30/20/10/25 мм (левое/верхнее/правое/нижнее); заголовки ЗАГЛАВНЫМИ по центру без точки; рисунки `Рисунок 1.1 – Название` по центру под рисунком, таблицы `Таблица 1.1 – Название` над таблицей; нумерация сквозная с титульника (на нём не ставится).
**Защита:** предзащита обязательна (без неё не допустят); антиплагиат (P-51) + нормоконтроль + рецензия внешнего специалиста; 30 мин всего, доклад ≤15 мин, публичная форма. **Оценка 100 баллов:** творчество 25 + научное мышление 25 + методы 12 + раскрытие темы 12 + ораторское 10 + командность 16.
**Трекер лабы → диплом:** Lab 1 (HCI основы + 10 аналогов + ТЗ прототипа) = Глава 1 (готова: `Reports/Lab1_Grafnot_Report_EN.txt` 661 строка / RU 682 строки / 2 docx для сдачи); Lab 2 (User Research, персоны) → Глава 1.3/постановка задач — ОЖИДАЕТСЯ; Lab 3 (прототип Figma) → Глава 2 — частично закрыта Draw.io-вайрфреймами (6 страниц) и React-прототипом; Lab 4 (юзабилити-тесты, SUS/время/сироты) → Глава 2/3 — ОЖИДАЕТСЯ; Lab 5+ (реализация) → Глава 3. Правило: новая лаба добавляется разделом и цитирует старые отчёты, не переписывает.
