# Fitts-отчёт S13 — «до» (S0) и «после» по 5 сценариям

Метод «после»: сид (2 заметки, задача, граф, `Clip me` с defaults), desktop 1440×900,
замер `getBoundingClientRect` центров и сторон последовательных целей (пробник — временный
скрипт поверх preview :5199, в репозиторий не входит). D — евклидово расстояние между
центрами, W — меньшая сторона цели-приёмника, ID = log2(D/W + 1).
Метод «до»: `docs/ux-baseline.md` §S0.5 (D — оценка по раскладке ±80px, W — DOM-замеры S0).

## 1. Добавить задачу

| | До (Tasks) | После (План/Список) |
|---|---|---|
| Действия мышью | 3 клика + текст (nav → поле → Добавить) | 2 клика + текст (стаб → поле → [Добавить]; Enter тоже добавляет) |
| Действия клавиатурой | нет | N, текст, Enter (серийный ввод, фокус остаётся) |
| Шаг поле → Добавить | D~180, W~90, ID~1.58 | D=165, W=44, ID=2.25 |
| Итог | 3 клика, кнопка sm h~28 (<32) | 2/0 кликов; композер вертикальный, [Добавить] во всю ширину 44px |

Найдено пробником 2026-10-14: раскрытый композер был сломан (legacy `.g-addtask{display:flex}`-строка
давила input до 26px, кнопка растягивалась до 395×140) — невидимо для e2e, видно глазом.
Починено в S13: `.t-composer{flex-direction:column; align-items:stretch}`.

## Бюджеты S13 (все доказаны G29-kpi, 7/7)

Новая задача: N + текст + Enter. Задача на день: клик по ячейке + текст + Enter.
Копия промпта (defaults подставлены): `/`, запрос, Enter, Ctrl+Enter; мышью 2 клика.
Смена заметки: 1 клик. Связь: `[[` + запрос + Enter. Удаление+возврат: 1 + 1 (задача:
Delete + Undo; заметка: ⋯/В корзину + Undo).
